## MobileVLCKit 3.7.5: GNU Lesser General Public License v2.1

- **What it is.** VLCKit is VideoLAN's Objective-C framework around libvlc. Sable uses it as the
  second playback engine, for files AVFoundation cannot play (MKV, WebM, AVI and others) and for
  image-based subtitles (PGS, VobSub).
- **Licence.** GNU Lesser General Public License, version 2.1. Full text:
  [`licenses/LGPL-2.1-VLCKit.txt`](licenses/LGPL-2.1-VLCKit.txt). The `COPYING.txt` shipped in the
  official binary archive is also placed in `Vendor/MobileVLCKit-COPYING.txt` when the framework
  is fetched.
- **Unmodified binary.** `scripts/fetch-vlckit.sh` downloads the official prebuilt MobileVLCKit
  binary that VideoLAN publishes for CocoaPods:
  `https://download.videolan.org/pub/cocoapods/prod/MobileVLCKit-3.7.5-a213fd11-6de05adc.tar.xz`.
  The script pins its SHA-256
  (`a76f7a6cfcde4209b56f943e6e18400659d8a7a93ff482f8b1d059468d11e6be`) and unpacks it as is.
  Sable does not patch, rebuild or statically link it.
- **Dynamic linking.** The framework is embedded at `Sable.app/Frameworks/MobileVLCKit.framework`
  and loaded at run time through `@rpath/MobileVLCKit.framework/MobileVLCKit`. CI checks this on
  every build (`tools/ci/verify_ipa.sh` checks the executable's load commands). The only change
  made at packaging time is code signing, which Xcode applies to every embedded framework when the
  app is signed. Signing does not change the library's code.
- **Source code.** VLCKit: <https://code.videolan.org/videolan/VLCKit> (release 3.7.5). libvlc
  (VLC media player 3.x): <https://code.videolan.org/videolan/vlc>. Release tarballs:
  <https://download.videolan.org/pub/videolan/>. In the artifact name `3.7.5-a213fd11-6de05adc`,
  the two hashes identify the VLCKit and VLC source revisions the binary was built from. The
  third-party libraries built into MobileVLCKit (FFmpeg/libavcodec and others) are covered by
  VideoLAN's own notices in that source tree.
- **Replacing or relinking the library (LGPL-2.1 §6).** You are free to use a modified version of
  MobileVLCKit with Sable:
  1. *From source (recommended).* Sable's complete source is in this repository. Build your own
     MobileVLCKit with the same public API (see VLCKit's `compileAndBuildVLCKit.sh`), put the
     resulting `MobileVLCKit.xcframework` in `Vendor/` (instead of running
     `scripts/fetch-vlckit.sh`), run `xcodegen generate` and build. Sable links against whatever
     framework is in `Vendor/`.
  2. *In a built app.* Unzip the IPA, replace `Payload/Sable.app/Frameworks/MobileVLCKit.framework`
     with your build (same install name `@rpath/MobileVLCKit.framework/MobileVLCKit`, arm64),
     sign the framework and then the app again (see [docs/SIGNING.md](docs/SIGNING.md)), zip it
     and install it.

  Because the framework is loaded dynamically by name, no Sable object files are needed to relink.

## Test fixtures

The sample videos in `Fixtures/` are generated by `Fixtures/make_fixtures.sh` with ffmpeg (Conway's
Game of Life pictures and synthesised tones). The dialogue and its Arabic reference translation
were written for this project. They contain no third-party footage. The fixtures are bundled only
in Debug builds, and CI checks that they are absent from Release builds.
